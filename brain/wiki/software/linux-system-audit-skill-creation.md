# Linux System Audit Skill Creation

A comprehensive Linux system audit prompt was saved as a reusable Hermes skill during a system performance investigation.

## Skill Details

- **Name:** `linux-system-audit`
- **Category:** devops
- **Location:** `~/.hermes/skills/devops/linux-system-audit/SKILL.md`
- **Trigger terms:** "audit my system", "linux audit", "performance check", "check my config"
- **Original prompt preserved at:** `references/original-prompt.md`

## Trigger

The skill was created from the master audit prompt that runs comprehensive system checks across GPU, kernel, audio, storage, and network subsystems. It was saved so the user can request a full audit with a simple phrase rather than pasting the multi-page prompt each time.
