# Free Agent Frameworks & Harnesses for LLMs

Curated overview of free/open-source frameworks for building agentic LLM applications.

## Popular / Major Frameworks

| Framework | Repo | Stars | Notes |
|---|---|---|---|
| **OpenAI Agents SDK** | [openai/openai-agents-python](https://github.com/openai/openai-agents-python) | 27k | Multi-agent orchestration by OpenAI |
| **LangGraph** | [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph) | 34k | Stateful graph-based agent orchestration |
| **CrewAI** | [crewAIInc/crewAI](https://github.com/crewAIInc/crewAI) | 53k | Role-based multi-agent collaboration |
| **smolagents** | [huggingface/smolagents](https://github.com/huggingface/smolagents) | 27.8k | Lean agents from HuggingFace — "think in code" |
| **DSPy** | [stanfordnlp/dspy](https://github.com/stanfordnlp/dspy) | 35k | Compiler for LM programs (Stanford) |
| **AutoGen (AG2)** | [microsoft/autogen](https://github.com/microsoft/autogen) | 58.8k | Multi-agent conversations; now in maintenance mode, community fork is AG2 |
| **Agno** (was PhiData) | [agno-ai/agno](https://github.com/agno-ai/agno) | Full-stack | Multi-modal, MCP, knowledge, memory |

## Lesser-Known but Quality

| Framework | Repo | What Makes It Unique |
|---|---|---|
| **Pydantic AI** | [pydantic/pydantic-ai](https://github.com/pydantic/pydantic-ai) | Type-safe, from the Pydantic team |
| **Atomic Agents** | [BrainBlend-AI/atomic-agents](https://github.com/BrainBlend-AI/atomic-agents) | Modular, composable, provider-agnostic |
| **Bee Agent Framework** | [i-am-bee/bee-agent-framework](https://github.com/i-am-bee/bee-agent-framework) | IBM's framework — MCP support, multi-modal |
| **Camel** | [camel-ai/camel](https://github.com/camel-ai/camel) | Role-playing multi-agent, research-heavy |
| **Maestro** | [Doriandarko/maestro](https://github.com/Doriandarko/maestro) | Lightweight multi-agent, BSD licensed |
