# Bosch WAN20161BY/24 — Control Module & Repair Guide

Research on finding the electronic control module (placa electronică) for a **Bosch WAN20161BY/24** washing machine.

## Confirmed Part Numbers

| Part Number | Description | Status |
|---|---|---|
| **11011036** | Leistungs/Invertermodul (power/inverter module) — unprogrammed | Available |
| **12016051** | Steuermodul (control module) Bosch/Siemens | **Discontinued** (stock exhausted on fixpart.de) |
| **10000839** | Sensor 3G for BLDC (sensor for lacquered board) | Available |

## Estimated Pricing (RON)

- **Control module (second-hand / aftermarket):** 200–500 RON
- **Control module (original new):** 500–1,200 RON
- **Power/inverter module:** 300–800 RON

## Where to Search

- **Romania:** [[emag.ro]], [[olx.ro]] (used/refurbished), [[cel.ro]]
- **Europe (ships to RO):** [ersatzteilshop.de](https://www.ersatzteilshop.de), [fixpart.de](https://fixpart.de)
- **Best bet:** Contact a Bosch authorized service center in Romania with the machine's E-Nr. (found on the sticker behind the door or on the back panel)

## Key Advice

- Use the E-Nr. (model serial code) from the machine's ID plate — not just the model name — to ensure correct part compatibility.
- The 12016051 control module is discontinued; look for compatible alternative part numbers or a refurbished unit.
- Power module (11011036) and control module (12016051) are separate PCBs — identify which one failed before ordering.
