# Git Repo Research Skill

The `git-repo-research` skill provides specialized capabilities for finding, analyzing, and evaluating GitHub repositories.

## Capabilities

- **Web search** for repositories by topic, language, or description
- **GitHub API** queries for repo metadata (stars, forks, activity, license)
- **Codebase analysis** — examine project structure, readme quality, recent commits
- **Comparison** — side-by-side evaluation of multiple repos on the same topic

## Usage

Triggered by queries about finding or comparing GitHub repositories. The skill combines web search (to discover relevant repos) with GitHub API calls (to fetch structured metadata). Works alongside the `github-operations` skill for deeper repo interaction.

## Related Skills

- `github-operations` — GitHub CLI/API for PRs, issues, code review (Hermes)
- `internet-research` — General web research (OpenCode)
- `research-assistant` — arXiv papers, blogs, prediction markets (Hermes)
